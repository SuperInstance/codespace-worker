# 🚀 Codespace Worker

Run commands remotely in ephemeral GitHub Codespaces. Perfect for cross-arch builds, agent offloads, and batch processing.

## Quick Start
```bash
codespace-worker SuperInstance/repo "npm run build && npm test"
```
